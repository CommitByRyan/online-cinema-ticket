## 1. 前期准备（软件安装与环境配置）

> 这一步是基础，请确保你的电脑上安装了以下软件。如果已经安装，可以跳过。

### 1.1 安装 JDK 17
- 下载地址：https://adoptium.net/ （选择 Eclipse Temurin 17，Windows 选 .msi 安装包）
- 安装时一路下一步，记住安装路径（例如 `C:\Program Files\Eclipse Adoptium\jdk-17.0.8.10-hotspot`）
- 配置环境变量（Windows）：
  - 右键“此电脑” → 属性 → 高级系统设置 → 环境变量
  - 新建系统变量 `JAVA_HOME`，值为 JDK 安装路径
  - 编辑 `Path` 变量，添加 `%JAVA_HOME%\bin`
- 验证：打开命令行（Win+R 输入 cmd），输入 `java -version`，看到 `openjdk version "17.0.8"` 即成功

### 1.2 安装 Maven（3.8+）
- 下载地址：https://maven.apache.org/download.cgi（选择 Binary zip，如 `apache-maven-3.9.5-bin.zip`）
- 解压到 `D:\maven`（不要有中文或空格）
- 配置环境变量：新建 `MAVEN_HOME` 指向解压目录，Path 添加 `%MAVEN_HOME%\bin`
- 验证：命令行输入 `mvn -version`，显示版本信息

### 1.3 安装 MySQL 8.0
- 下载地址：https://dev.mysql.com/downloads/mysql/（选择 Windows (x86, 64-bit), MSI Installer）
- 安装教程参考：https://www.runoob.com/mysql/mysql-install.html
- 关键步骤：选择 Developer Default，设置 root 密码（请记住，例如 `123456`），端口默认 3306
- 安装后可以用自带的 MySQL Workbench 或命令行连接测试

### 1.4 安装 IntelliJ IDEA（社区版即可）
- 下载地址：https://www.jetbrains.com/idea/download/（Community 版免费）
- 安装后打开，第一次会让你选择主题，选自己喜欢的

### 1.5 安装 Git
- 下载地址：https://git-scm.com/download/win（默认选项安装）
- 验证：命令行输入 `git --version`

## 2. 创建 SpringBoot 项目（IDEA 图形化操作）

> 这一步会生成一个空的 SpringBoot 项目，包含基础的 Maven 结构和配置文件。

1. 打开 IntelliJ IDEA，点击 `New Project`
2. 左侧选择 `Spring Initializr`（如果找不到，先安装 Spring Assistant 插件）
   - **注释**：Spring Initializr 是官方项目生成器，自动帮你生成 pom.xml 和主类。
3. 右侧配置：
   - **Server URL**：使用默认 `https://start.spring.io`（国内用户可改用 `https://start.aliyun.com`，更快）
   - **Name**：`online-ordermeal`
   - **Location**：选择你的工作目录（例如 `D:\projects`）
   - **Language**：Java
   - **Type**：Maven
   - **Group**：`com.team`（公司/组织名，可自定义）
   - **Artifact**：`online-ordermeal`（项目名）
   - **Package name**：`com.team.ordermeal`（包名，代码会放在这个包下）
   - **JDK**：选择 17（如果列表里没有，点击 Add JDK 选择安装路径）
   - **Packaging**：Jar（可执行 Jar 包）
4. 点击 `Next`
5. **选择依赖（Dependencies）**：勾选以下选项（可以搜索）
   - ✅ **Spring Web**（构建 Web 应用，包含 Tomcat）
   - ✅ **Thymeleaf**（模板引擎，用来写 HTML）
   - ✅ **Spring Boot DevTools**（热部署，修改代码自动重启）
   - ✅ **Lombok**（简化实体类，减少 getter/setter）
   - ✅ **MySQL Driver**（连接 MySQL）
   - ⚠️ 注意：MyBatis 需要手动添加，因为 Spring Initializr 不提供，我们在下一步手动写 pom.xml
6. 点击 `Finish`
7. IDEA 会自动下载依赖（第一次比较慢，耐心等待右下角进度条完成）

## 4. 配置 application.properties（连接数据库）

> 这个文件告诉 SpringBoot 如何连接 MySQL 数据库。

1. 找到 `src/main/resources/application.properties` 文件（如果没有就创建）
2. 用以下内容替换（每一行都有注释）：

```properties
# 数据库连接配置
# spring.datasource.url: 数据库地址 jdbc:mysql://localhost:3306/ordermeal 
#   - localhost 是本机，3306 是 MySQL 默认端口
#   - ordermeal 是数据库名（我们后面会创建）
#   - useSSL=false 关闭 SSL 加密（开发环境）
#   - serverTimezone=Asia/Shanghai 设置时区
#   - characterEncoding=utf8 支持中文
spring.datasource.url=jdbc:mysql://localhost:3306/ordermeal?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8

# 数据库用户名（通常是 root）
spring.datasource.username=root

# 数据库密码（你在安装 MySQL 时设置的密码）
spring.datasource.password=123456

# MySQL 驱动类名（新版本可以省略）
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# MyBatis 配置
# mapper.xml 文件存放位置（后面我们会创建 mapper 文件夹）
mybatis.mapper-locations=classpath:mapper/*.xml

# 实体类包路径（让 MyBatis 自动识别别名，比如写 User 不用写全路径）
mybatis.type-aliases-package=com.team.ordermeal.entity

# Thymeleaf 模板配置
# 关闭缓存，修改 HTML 后立即生效（开发时使用，生产环境要改为 true）
spring.thymeleaf.cache=false

# 服务器端口（默认 8080，可以不改）
server.port=8080

# 订单过期时间（分钟），我们设置为 15
order.expire-minutes=15
```

```sql
CREATE TABLE tb_address (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,

    receiver_name VARCHAR(50) NOT NULL COMMENT '收货人姓名',
    phone VARCHAR(20) NOT NULL COMMENT '收货人电话',
    province VARCHAR(50),
    city VARCHAR(50),
    district VARCHAR(50),

-- ======================== 订单表 ========================
CREATE TABLE tb_order (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,

-- ======================== 订单明细表 ========================
CREATE TABLE tb_order_item (
```

### 6.2 创建统一返回类 Result

- 路径：`common/result/Result.java`
- 代码（带详细注释）：

```java
package com.team.ordermeal.common.result;

/**
 * 统一 API 返回结果
 * 所有 Controller 的方法都要返回这个对象，保证前端处理一致
 * @param <T> 返回的数据类型
 */
public class Result<T> {
    private int code;   // 状态码，200表示成功，500表示失败
    private String msg; // 提示信息
    private T data;     // 实际数据

    // 构造器私有，只能通过静态方法创建
    private Result() {}

    // 成功返回（不带数据）
    public static <T> Result<T> success() {
        Result<T> result = new Result<>();
        result.setCode(200);
        result.setMsg("success");
        return result;
    }

    // 成功返回（带数据）
    public static <T> Result<T> success(T data) {
        Result<T> result = new Result<>();
        result.setCode(200);
        result.setMsg("success");
        result.setData(data);
        return result;
    }

    // 失败返回（自定义错误信息）
    public static <T> Result<T> error(String msg) {
        Result<T> result = new Result<>();
        result.setCode(500);
        result.setMsg(msg);
        return result;
    }

    // 失败返回（自定义错误码和信息）
    public static <T> Result<T> error(int code, String msg) {
        Result<T> result = new Result<>();
        result.setCode(code);
        result.setMsg(msg);
        return result;
    }

    // getter 和 setter（Lombok 可以简化，但这里手动写，保证小白能看懂）
    public int getCode() { return code; }
    public void setCode(int code) { this.code = code; }
    public String getMsg() { return msg; }
    public void setMsg(String msg) { this.msg = msg; }
    public T getData() { return data; }
    public void setData(T data) { this.data = data; }
}
```

```java
/**
 * 订单状态枚举
 * 定义所有可能的订单状态，避免字符串硬编码
 */
public enum OrderStatusEnum {
    PENDING("待支付", 0),
    PAID("已支付", 1),
    CONFIRMED("商家已接单", 2),
    PREPARING("制作中", 3),
    DELIVERED("配送中", 4),
    COMPLETED("已完成", 5),
    CANCELLED("已取消", -1);

    private String desc;  // 中文描述
    private int code;     // 数字代码

    // 构造器
    OrderStatusEnum(String desc, int code) {
        this.desc = desc;
        this.code = code;
    }

    // getter
    public String getDesc() { return desc; }
    public int getCode() { return code; }

    // 根据数字代码获取枚举（供数据库转换用）
    public static OrderStatusEnum fromCode(int code) {
        for (OrderStatusEnum s : values()) {
            if (s.code == code) return s;
        }
        return null;
    }

    // 判断该状态是否允许用户取消（用于业务逻辑）
    public boolean canCancel() {
        return this == PENDING || this == PAID;  // 待支付和已支付（商家未接单前）可取消
    }
}
```

### 7.1 订单状态机工具类（校验状态流转）

- 路径：`common/utils/OrderStateMachine.java`

```java
package com.team.ordermeal.common.utils;

import com.team.ordermeal.common.enums.OrderStatusEnum;
import com.team.ordermeal.common.exception.BusinessException;

/**
 * 订单状态机：定义哪些状态转换是合法的，防止非法操作
 */
public class OrderStateMachine {

    /**
     * 检查从 from 状态是否可以转换为 to 状态
     * @param from 当前状态
     * @param to   目标状态
     * @throws BusinessException 如果不允许转换则抛出异常
     */
    public static void checkTransition(OrderStatusEnum from, OrderStatusEnum to) {
        if (from == null || to == null) {
            throw new BusinessException("订单状态无效");
        }
        boolean allowed = false;
        switch (from) {
            case PENDING:
                allowed = (to == OrderStatusEnum.PAID || to == OrderStatusEnum.CANCELLED);
                break;
            case PAID:
                allowed = (to == OrderStatusEnum.CONFIRMED || to == OrderStatusEnum.CANCELLED);
                break;
            case CONFIRMED:
                allowed = (to == OrderStatusEnum.PREPARING);
                break;
            case PREPARING:
                allowed = (to == OrderStatusEnum.DELIVERED);
                break;
            case DELIVERED:
                allowed = (to == OrderStatusEnum.COMPLETED);
                break;
            default:
                allowed = false;
        }
        if (!allowed) {
            throw new BusinessException(String.format("订单状态不允许从 %s 修改为 %s", from.getDesc(), to.getDesc()));
        }
    }
}
```

```java
package com.team.ordermeal.service.impl;

import com.team.ordermeal.common.enums.OrderStatusEnum;
import com.team.ordermeal.entity.Order;
import com.team.ordermeal.mapper.OrderMapper;
import com.team.ordermeal.service.OrderService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import java.time.LocalDateTime;
import java.util.List;

@Service
@Transactional  // 开启事务，确保数据库操作的一致性
public class OrderServiceImpl implements OrderService {

    @Autowired
    private OrderMapper orderMapper;

    @Override
    public int cancelExpiredPendingOrders() {
        // 1. 查询所有过期的待支付订单
        List<Order> orders = orderMapper.selectExpiredPendingOrders(LocalDateTime.now());
        // 2. 遍历并修改状态为 CANCELLED
        for (Order order : orders) {
            order.setStatus(OrderStatusEnum.CANCELLED.name());
            orderMapper.updateById(order);
        }
        return orders.size();  // 返回取消的数量
    }
}
```

```java
import com.team.ordermeal.service.OrderService;

import org.slf4j.LoggerFactory;

import org.springframework.scheduling.annotation.EnableScheduling;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;

@Component
@EnableScheduling  // 开启定时任务

    @Autowired
    private OrderService orderService;

    @Scheduled(fixedDelay = 30000)
```
